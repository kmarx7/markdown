# Antigravity Git Branching Rules

Whenever a new feature is requested, or when an existing feature is modified or updated, follow these rules:

1. **Create a Dedicated Branch**: 
   Before making any code edits, create and switch to a new Git branch.
   - Branch naming convention: `feature/<feature-name>` (e.g., `feature/custom-shortcut`).
   - If it's a bug fix, use `fix/<bug-name>`.

2. **Work Locally**:
   Implement all changes on that branch.

3. **Commit Cleanly**:
   Create granular, well-described commits for the feature.
